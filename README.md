# Briefing de la mañana

Web app instalable (PWA) con el resumen diario de noticias: Vigo, Galicia, España, Celta, UFC, F1, mercados (PIAS) y sector asegurador.

- App: https://alexis21091.github.io/briefing/
- Instalar en iPhone: abrir en Safari → Compartir → Añadir a pantalla de inicio.
- Datos: `data/AAAA-MM-DD.json` (una edición por día) y `data/index.json` (lista de ediciones, la más reciente primero).
- Las ediciones las genera cada mañana una tarea programada de Claude.
- `.nojekyll` evita el procesado de Jekyll en GitHub Pages.
